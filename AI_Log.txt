[User]
What are EF Core migrations?

[Assistant]
EF Core migrations are versioned changes to a database schema based on changes to the C# data models. A migration records how to create or alter tables, and applying it updates the database while generally preserving existing rows. Typical commands are dotnet ef migrations add InitialCreate and dotnet ef database update. Migrations define the schema; API code is still needed to read and save ticket data.

[User]
How do I add the dotnet-ef tool, apt-get?

[Assistant]

For a project-local tool, from the repository root, create a tool manifest once with dotnet new tool-manifest, then run dotnet tool install dotnet-ef and verify with dotnet ef --version. A global install is also available with dotnet tool install --global dotnet-ef.
